## Project overview

FasterThenLook is an early-stage iOS app (SwiftUI + SwiftData) for tracking vehicles: fuel logs, maintenance schedules, and repair history. Bundle ID `com.jumpahead.FasterThenLook`, iOS 26.2 deployment target, Swift 5. No SPM dependencies. The UI layer is essentially unbuilt (`ContentView` is currently empty) — most of what exists today is the SwiftData model layer.

## Commands

Build and test via `xcodebuild` (no SPM/CocoaPods; open in Xcode also works):

```sh
# Build
xcodebuild -project FasterThenLook.xcodeproj -scheme FasterThenLook -destination 'platform=iOS Simulator,name=iPhone 17' build

# Run all tests (unit + UI)
xcodebuild -project FasterThenLook.xcodeproj -scheme FasterThenLook -destination 'platform=iOS Simulator,name=iPhone 17' test

# Run a single test (Swift Testing target, FasterThenLookTests)
xcodebuild -project FasterThenLook.xcodeproj -scheme FasterThenLook -destination 'platform=iOS Simulator,name=iPhone 17' test -only-testing:FasterThenLookTests/FasterThenLookTests/example

# Run a single UI test (XCTest target, FasterThenLookUITests)
xcodebuild -project FasterThenLook.xcodeproj -scheme FasterThenLook -destination 'platform=iOS Simulator,name=iPhone 17' test -only-testing:FasterThenLookUITests/FasterThenLookUITests/testExample
```

Unit tests use the **Swift Testing** framework (`@Test`, `#expect`), not XCTest — `FasterThenLookTests.swift`. UI tests use XCTest — `FasterThenLookUITests/`.

```sh
# Lint (config: .swiftlint.yml)
swiftlint

# Regenerate Strings+Generated.swift / Assets+Generated.swift after editing
# Resources/Strings/en.lproj/Localizable.strings or Resources/Assets.xcassets
swiftgen
```

`swiftgen` and `swiftlint` are installed via Homebrew, not SPM plugins — run them manually after touching localized strings or asset catalog entries. `FasterThenLook/Generated/` is gitignored and regenerated by swiftgen; don't hand-edit `Strings+Generated.swift` or `Assets+Generated.swift`.

## Architecture

- **Persistence**: SwiftData. `FasterThenLookApp.swift` builds the single `ModelContainer` from a `Schema` listing all five `@Model` types (`AppSettings`, `Car`, `FuelLog`, `MaintenanceItem`, `RepairLog`) and injects it via `.modelContainer(...)`. Any new `@Model` type must be added to that schema array or it won't persist.
- **Model graph**: `Car` is the root entity, with cascade-delete `@Relationship`s to `MaintenanceItem`, `RepairLog`, and `FuelLog` (deleting a `Car` deletes its children). `RepairLog` can optionally link back to a `MaintenanceItem` via `linkedMaintenanceItem`. `AppSettings` is a standalone singleton-style model (units/currency/notification prefs), not related to `Car`.
- **Units/enums**: Domain enums (`FuelType`, `TriggerType`, `DistanceUnit`, `FuelUnit`, `EconomyUnit`) are declared `nonisolated` and `Codable` alongside the model that owns them, in `Models/`.
- **Localization/assets**: swiftgen generates type-safe accessors — `L10n` for `Localizable.strings`, `Asset` for `Assets.xcassets` — into `FasterThenLook/Generated/`, configured by `swiftgen.yml`. Add new strings/assets to the source files, then re-run `swiftgen` before referencing `L10n.*` / `Asset.*` in code.

## SwiftLint conventions (enforced, see `.swiftlint.yml`)

- **No force unwrapping** (`force_unwrapping` is an `error`, not a warning) — this app handles money and vehicle data, avoid `!`.
- **Use `Decimal`, not `Double`, for monetary fields** — a custom rule errors on any `price`/`amount`/`total`/`tax`/`tip`/`cost` property typed `Double`. Note the existing `FuelLog`/`RepairLog` price fields (`primaryPriceTotal`, `priceOfItem`, `priceOfWork`, etc.) predate this rule and are still `Double`; don't propagate that pattern into new money fields.
- **No `print()`** — custom rule warns; use structured logging instead.
- File length warns at 400 lines/errors at 600; type bodies warn at 250 lines; functions warn at 40 lines/error at 60.
